# 探学营第二阶段项目

使用学生数据集，挖掘社交媒体时长、AI 工具使用、睡眠、运动、心理评分、倦怠等级等特征，训练逻辑回归模型，预测学生学业失败风险。

依赖库：[dependency_library.md](https://github.com/YueTianBanana/student_failure_predict_project/blob/main/dependency_library.md)，训练数据：[AI_SocialMedia_Stud... .csv](https://github.com/YueTianBanana/student_failure_predict_project/blob/main/AI_SocialMedia_Student_Health_Dataset_clean.csv)。

如果要预测自己的数据，可以在[student_failure_prediction.ipynb](null)中顺序运行第一、二个代码框，在第二个代码框运行时输入学生信息

因为数据限制，仅支持High School、College、University三个年级的预测。
